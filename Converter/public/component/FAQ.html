Menggunakan sistem virtual Python
Web ini menggunakan semacam "Sistem Virtual" untuk memuat environment Python. Sistem ini berjalan sepenuhnya diperangkatmu. Tenang, ini tidak memakan penyimpanan besar (sistem virtual ini cuma sekitar 10MB). Saat kamu tutup web ini, seluruh sistem virtual akan terhapus dan dihancurkan
